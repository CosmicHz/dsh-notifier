# 视觉定稿：精致、安静、清晰的原生控制面

这是一件DSH内日常使用的工具。品质体现在排版、密度、层级、状态和动作完成度，不做营销首页、霓虹大背景、玻璃拟态或满屏渐变。独特性来自清晰的任务叙事、连接状态标识和一致细节；不覆盖宿主导航或重造App Shell。

## 画面构成（固定）

主容器最大1120px，左右居中；宽屏内边距32px，720–1023为24px，<=719为16px。主内容宽度由宿主实际panel决定，不能用window宽度假定有完整屏幕。
页头：标题+一行说明左对齐，主动作右对齐；窄屏主动作下一行全宽。页头到内容32px；section间24px，标题到内容12px，表单字段间16px。
概览：上方一条工作状态摘要，中央“需要你处理”主要区与“连接状态”次要区，宽屏比例约2:1；底部最近活动。没有待办时中央是轻量“目前无需处理”，不撑出空卡。
通知：单列连接列表，行高至少76px但随文字增长，按应用分组；密度适合扫描。手机控制：连接列表+选中连接的配对过程，不同时铺满六张卡。待处理：300px列表+剩余详情，容器不足900px改stack。设置：760px阅读宽度、section分隔。
五页分别按上述布局，不采用通用等宽卡片墙。

## 字体与视觉层级

字体只用宿主system stack，中文PingFang SC/Microsoft YaHei，英文system-ui；不下载装饰字体。标题20/28px weight500；section14/22 weight500；正文14/22；表单/主要动作14/20 weight500；辅助12/18；代码13/20等宽。
正文行长最大72ch；中文说明最大约40字一行（通过容器宽度而非强行插换行）。长英文word-break:break-word；标识符overflow-wrap:anywhere。数字计时tabular-nums，不能所有正文等宽。
绝不通过极低透明度区分层级，正文/辅助满足4.5:1，大字/边框焦点适用项3:1。

## 色彩与层次

宿主token第一优先，缺失才用DESIGN-TOKENS.json。背景base与surface只小幅明度差；默认卡片边框1px，悬停提升边框对比，不整块变蓝。Accent仅主动作/选中/焦点，单视口主动作不超过一个页级和一个当前操作区级。
成功用深绿文字+浅绿底，警告用深棕文字+浅黄底，错误用深红文字+浅红底；状态始终图标+文字，不靠色点。图标20px，线宽1.75px，圆端圆角；从固定本地图标集中取，不混emoji/不同线宽。
渠道标记32px圆角8px，文本徽标两字符，上方统一几何外框；有清晰合法来源的现有图标才使用。用户资产/图标均本地，不对外请求。
圆角：输入/按钮8，状态徽标6，panel12，dialog16。只浮层用阴影，普通卡不堆多重阴影。按钮触达>=44×44；小图标视觉20但点击盒44。

## 动效（有目的且可关闭）

hover/press120ms，淡入/状态切换160ms，panel展开220ms；统一cubic-bezier(.2,0,0,1)。只动画opacity/transform；panel位移不超过8px，无弹簧/摇晃/持续脉冲。
页面切换保持原内容到新数据可用，加载<=150ms不闪spinner；超过150ms显示与最终结构同尺寸skeleton；超过8s提供“仍在等待”和取消/重试（只对可安全重试动作）。
保存成功就地状态更新，Toast补充；计时每秒更新数字但不跳动布局。prefers-reduced-motion时去掉transform与非必要transition，保留状态文本。

## 细节禁止项

无截断的主要操作名称、无裁掉焦点环、无横向主体滚动、无重复双滚动条、无页头突然高度跳变、无只有图标无accessible name的动作、无把技术码当正文、无英文溢出/中文标点孤行的明显排版失误。
错误/空态/加载态与正常页使用相同栅格和类型系统。长列表保留行基线和信息主次；不是每个字段都加border卡片。
