# UI实现入口（UX修订2.1）

本文件定义UI技术边界；11定义流程，12定义视觉，15定义字段，19定义动作接线；RPC唯一见03，13为实施后的品质门槛。

只用宿主 React，不引入组件框架。主题 CSS 使用 --dsw-alias-label-primary、--dsw-alias-label-secondary、--dsw-alias-bg-base、--dsw-alias-bg-layer-2、--dsw-alias-border-l2、--dsw-alias-interactive-bg-hover 及 frozen client 的实际 token。fallback：浅背景#fff/文字#1f2329，深背景#151517/文字#f2f3f5，accent#4d6bfe；主题由宿主决定。容器 .dnv1，间距4/8/12/16/24/32，输入44px，按钮min44px，卡片圆角12px，正文14/22px，标题20/28px weight500；每页采用12定义的专属布局，不使用通用等宽卡片网格。

组件固定 App、Tabs、OverviewPage、NotificationsPage、PrivateChatPage、PendingPage、SettingsPage、AccountDialog、DestinationDialog、PairingDialog、ConfirmDialog、Field、Toast、EmptyState、ErrorState、Pagination。源码 ui/ 内拆分，禁止一个1500行文件。

controller只通过03 RPC，记录 storeRevision与surfaceVersion、connectionState、pending request。surface.wait 最多一个长轮询；隐藏标签页暂停，恢复先 fetch；错误1/2/5/10s退避；组件卸载 abort。不在刷新时清空已有数据，显示 stale。写入期间禁用重复提交；409/CONFLICT 刷新记录并保留用户输入提示冲突，不自动覆盖。

所有页面首次 loading、无配置 empty、正常 ready、失败 error、断线 stale 五态。所有文案 strings.zh/en 同键，语言跟随宿主。空页面不放 Coming soon。页面入口只五项，当前 tab 键盘左右切换。Toast成功4s，错误需关闭。Dialog role=dialog、aria-modal、焦点锁定、Esc关闭无提交、关闭返回触发按钮。

设置页只读 CLI 指引必须给出精确命令，不能放未连接的“导入/恢复”按钮。新备份通过实际 CLI 完成，不让浏览器下载明文凭据。
账号表单由 registry fields 生成，必填在 save 时验证，connection disabled 的方向不要求凭据；enable 时必须完整。密码字段初值空+“已配置”标记，留空保持，清除单独复选动作；不能把••••保存成 token。
通知测试按11的人话标签表达 accepted/confirmed/failed/uncertain/skipped 原词义；不把mock回执画成成功。配对显示完整8位、倒计时、复制、撤销；过期禁复制并可重新生成。二维码由登录 payload 提供，支持文本/复制回退；二维码渲染若加库只能开发构建内嵌，不加生产运行依赖。
选择“删除账号”确认文案明确目的地/授权也删除；提交走一次后端操作，不由 UI 顺序调用多次删除。
